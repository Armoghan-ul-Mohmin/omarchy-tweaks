<h1 align='center'> Omarchy Tweaks </h1>

My personal Omarchy environment, tweaksd to fit my workflow.

Omarchy Tweaks is my personal collection of customizations for Omarchy, built to shape the desktop around the way I work.

This repository will serve as the home for my configurations, scripts, keybindings, application preferences, and other system tweaks as the setup evolves.

> **Note:** This project is a work in progress. It is currently in its initial stage, and installation scripts and customizations may not yet be available.

## What to Expect

* **Configuration** — Personal desktop and application settings.
* **Keybindings** — Workflow-focused shortcuts and controls.
* **Automation** — Scripts to simplify setup and maintenance.
* **Customization** — Themes, tweaks, and other desktop refinements.
* **Applications** — Personal application preferences and related setup.

These are the project's intended areas of development, not a guarantee that each is already implemented.

## Installation

Installation instructions will be added once the bootstrap script and initial configuration are ready.

For now, you can clone the repository to explore its contents:

```bash
git clone --depth=1 https://github.com/Armoghan-ul-Mohmin/omarchy-tweaks.git ~/.omarchy-tweaks
cd ~/.omarchy-tweaks
```

## Disclaimer

This repository reflects my personal workflow and preferences. It is not intended to be a universal Omarchy configuration.

Future installation scripts may change system settings, install or remove packages, and modify existing configurations. Review the scripts before running them, and back up any important data or configuration files.

Use at your own discretion.
