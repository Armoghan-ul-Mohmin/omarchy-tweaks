Expansions#

Expressions#

ExpressionExampleDescription
!! sudo !! Last command (sudo !!)
!* vim !* Last command's parameters (vim !*)
!^ Last command's first parameter
!$ Last command's last parameter
!<n> !42 Event number 42 from history
!-<n> !-2 nth command back
^old^new ^configure^make Quick substitution in the last command
!?ls<tab> sudo !?mv Command and params of last ls command
!?ls?:* <tab> Params of last ls command

In this config bang_hist is off (Atuin owns history — see History & Atuin), so !!, !$ etc. are disabled by default. Re-enable with setopt bang_hist in 10-options.zsh if you want them back.

History & Atuin#

Keys / commandAction
Ctrl+RAtuin history search (bound in both emacs and viins)
↑ / ↓Atuin per-line history search (bound by atuin init)
atuin search "…"Search history from the CLI
atuin statsHistory statistics
atuin importImport history from other shells

Zsh itself keeps no history file in this config — HISTFILE is unset and share/append/inc_append/extended_history are all off, so Atuin is the single source of truth. bang_hist and hist_verify are also off. Autosuggestions therefore fall back to the completion engine as well as (empty) local history: ZSH_AUTOSUGGEST_STRATEGY=(history completion).

Source of truth: dotfiles/zsh/lib/10-options.zsh. Prefix a command with nh or , if you don't want it recorded.

Job control#

ExpressionDescription
cmd &Run in background
Ctrl+ZSuspend the foreground job
jobsList jobs (%1 refers to the first)
fg %1Bring job 1 to the foreground
bg %1Resume job 1 in the background
disown %1Remove job from the table (survives shell exit)
wait %1Block until job finishes

notify is set, so background jobs report their status immediately. Beware: Ctrl+Z is rebound to the zoxide jump widget in this config — suspend with suspend or rebind it (details).
