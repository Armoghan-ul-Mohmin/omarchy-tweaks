Notes & hashing#

Notes

FunctionCalled asDescription
_notenote · note new · note search · note recent · note open Dashboard (choose with gum choose) or direct action. New: title → body (gum write, Ctrl+D saves) → optional tags, appended as a ## title section with a timestamp. Search: ripgrep + fzf with a bat markdown preview, then page the hit. Recent: last 20 headings in gum pager. File: $NOTES_FILE (default ~/Documents/notes.md)
_notesnotes Open the notes file in $VISUAL (creates it first, shows file info card)

Hashing

FunctionCalled asDescription
_hashhash · hash FILE · hash FILE sha512 With no file: pick one from fzf (eza/bat preview). Algorithm: gum choose md5 / sha1 / sha256 / sha512 / all. Files print one digest; directories walk every file (sorted) and pipe through the same checksum tool, so folders get a single combined hash. Falls back to md5/shasum on non-GNU systems
