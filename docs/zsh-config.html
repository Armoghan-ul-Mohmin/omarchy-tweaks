Architecture#

Load flow#

.zshrc is only an entry point — the real config lives in lib/*.zsh, sourced in alphabetical order: 

# never run in non-interactive shells
[[ $- != *i* ]] && return

# directory of this file — absolute and symlink-safe
typeset -g ZSHRC_DIR="${${(%):-%x}:A:h}"

# load modules in order
for _zshrc_module in "$ZSHRC_DIR"/lib/*.zsh(N); do
  source "$_zshrc_module"
done

# secrets last
[[ -f "$HOME/.secrets.zsh" ]] && source "$HOME/.secrets.zsh"
ModuleContains
.zshrcInteractive guard, ZSHRC_DIR resolution, module loop, ~/.secrets.zsh
00-env.zshEnvironment variables (editor, pager, fzf, plug, PATH, starship)
10-options.zshsetopts, Atuin-compatible history settings, autosuggest strategy
20-plugins.zshplug.zsh install + plugins + tool inits + you-should-use
30-fzf-tab.zshfzf-tab zstyles/previews + the fzf ZLE widgets
40-aliases.zshAliases only (cheatsheet)
50-functions.zshGum-powered functions (cheatsheet)
60-keybindings.zshbindkey -e, run-tui, widgets, key bindings

Numbered prefixes control load order — add a module by dropping NN-name.zsh into lib/; nothing else changes.

Testing & installing#

# test without touching ~/.zshrc
ZDOTDIR=/path/to/omarchy-tweaks/dotfiles/zsh zsh -i
zsh-dev                       # same thing, wrapper in bin/

# install for real (symlink, never copy)
ln -sf /path/to/omarchy-tweaks/dotfiles/zsh/.zshrc ~/.zshrc

# day-to-day
zshrc                         # pick a module, edit, optionally reload
reload                        # exec zsh

ZSHRC_DIR is exported, so reload and zshrc keep working after a restart. Machine-specific values (tokens, private env) belong in ~/.secrets.zsh, sourced last.

Keybindings — 60-keybindings.zsh#

Keymap & run-tui#

bindkey -e sets the emacs keymap as main (some environments alias main to viins — this line is what keeps bindings where you expect them). Every launcher widget goes through run-tui, which hands the program the real tty, restores stty sane afterwards and redraws the prompt. bin/keybind-help shows all of this inside the shell (Alt+? or Alt+/).

Conventions#

House rules#

  • Aliases live in 40-aliases.zsh, functions in 50-functions.zsh.
  • Function naming: implementation _name, exposed through a public alias (ports="_ports") so aliases behave like commands.
  • Anything interactive uses gum (input, choose, confirm, filter, table).
  • gum table from a pipe must use --print — interactive table mode aborts when stdin is piped.
  • Inside functions call command git / command du… to bypass aliases like du='_du'.
  • Plugins are declared with plug only; tool inits with plug eval.
  • New keybinding = zle -N + bindkey + an entry in bin/keybind-help.
  • Secrets and private env go into ~/.secrets.zsh, never into the repo.
