Everyday git#

Basics#

CommandDescription
git clone URLClone a repository
git initCreate a repository here
git status -sbShort status with branch line (alias gs)
git add fileStage a file
git commit -m "msg"Commit staged changes
git commitOpen the editor for a message
git diffUnstaged changes
git diff --stagedStaged changes (alias gds)
git log --oneline --graph --decorate -20Readable history (alias glogp)
git show HEADShow the last commit incl. patch

CommandDescription

git restore --staged fUnstage (keep the change)

Branching#

CommandDescription

git rebase mainReplay current branch onto main

Remote#

CommandDescription

Stash#

CommandDescription
git stash push -u -m "wip"Stash tracked + untracked with a message (gsh)
git stash listList stashes (gshl)
git stash popApply and drop the newest stash (gshp)
git stash apply stash@{1}Apply without dropping
git stash dropDiscard the newest stash

Undo#

CommandDescription
git restore fileDiscard local changes to a file
git commit --amendRewrite the last commit (gamend = guided)
git commit --amend --no-editAmend keeping the message
git reset --soft HEAD~1Undo commit, keep changes staged
git reset HEAD~1Undo commit, keep changes unstaged
git reset --hard HEAD~1Undo commit and changes (destructive)
git revert SHANew commit that undoes an old one (safe for shared branches)
git cherry-pick SHACopy a commit onto the current branch

reset --hard and clean destroy work — check git status and git stash first. git reflog rescues most accidents.

Gum wrappers#

Plain aliases live on My Aliases → Git. These g… commands wrap git with gum prompts and feedback — the functions are in Functions → Git:

CommandWhat it does
gfetch / gpull / gpushRuns the command, prints an info line before and a green/red result after; returns git's exit code
gcommit "msg"Commits; with no arguments prompts with gum input
gcomitConventional-commit wizard: pick type → optional scope → message → optional body
gclonePrompts for a repository URL if none is given
gcoPrompts for a branch name if none is given
gbranchLists local branches in gum choose and switches
gamendAmend with the current subject/body prefilled for editing
 
gcomit            # wizard: fix(docs): …
gcommit "chore: bump deps"
gbranch           # pick a branch from a list
gpush             # → 󰊢 Pushing from remote… / Push complete
